Object-Oriented Programming Concepts

An object is a software bundle of related state and behavior. Software objects are often used to model real-world objects in everyday life. A class is a blueprint or prototype from which objects are created.

Inheritance and Polymorphism

Inheritance provides a powerful mechanism for code reuse. A class inherits state and behavior from its superclass. Polymorphism allows subclasses to define their own unique behaviors while sharing the common interface of the parent type.

Interfaces and Encapsulation

An interface is a contract between a class and the outside world. When a class implements an interface, it promises to provide the behavior published by that interface. Encapsulation hides internal state and requires all interaction to be performed through an object's public methods.
