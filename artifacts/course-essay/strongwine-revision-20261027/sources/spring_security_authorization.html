Authorization Architecture

Spring Security Documentation. URL: https://docs.spring.io/spring-security/reference/servlet/authorization/architecture.html

Authorization Filter and Access Decision Management

Spring Security's authorization architecture relies on the AuthorizationFilter inserted into the standard Servlet FilterChain. Every incoming HTTP request is evaluated against URL authorization rules configured in the SecurityFilterChain bean.

Method-Level Security

In addition to web-tier URL authorization, Spring Security provides annotations like @PreAuthorize and @Secured to enforce fine-grained access control directly at the service method level, ensuring that sensitive domain operations cannot be invoked even if web filters are misconfigured.
