Role-Based Access Control Principles

Role-Based Access Control (RBAC) regulates user access to system resources based on assigned organizational roles. In an enterprise web application, privileges are granted to roles rather than individual accounts.

Implementation in Enterprise Java

Roles are represented as instances of GrantedAuthority with a ROLE_ prefix (e.g. ROLE_ADMIN, ROLE_STAFF, ROLE_SHIPPER, ROLE_CUSTOMER). Authentication tokens (such as UsernamePasswordAuthenticationToken) carry the authenticated principal's authorities, which are checked by the security subsystem prior to dispatching HTTP requests or executing privileged services.
