OpenAPI Specification v3.1.0: RESTful API Modeling and Design

OpenAPI Initiative, Linux Foundation, 2021. URL: https://spec.openapis.org/oas/v3.1.0

RESTful API Contract Modeling

The OpenAPI Specification (OAS) defines a standard, language-agnostic interface description for HTTP REST APIs. It allows humans and computers to discover and understand the capabilities of a service without access to source code or additional documentation.

Components and Schemas

OAS v3.1 aligns with JSON Schema draft 2020-12, enabling rigorous definition of request bodies, URL path parameters, response payloads, HTTP status codes (200 OK, 201 Created, 400 Bad Request, 401 Unauthorized, 403 Forbidden, 404 Not Found), and OAuth2/Bearer authentication schemes for e-commerce endpoints.
