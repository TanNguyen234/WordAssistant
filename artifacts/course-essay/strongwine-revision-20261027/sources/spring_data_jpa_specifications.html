Dynamic Querying with the Specification Pattern

JPA 2 introduces a criteria API that you can use to build queries programmatically. Spring Data JPA allows execution of dynamically composed predicates via the org.springframework.data.jpa.domain.Specification interface.

Composition of Predicates

Specifications can be easily combined using where(), and(), and or() methods to build complex multi-attribute search filters (e.g. filtering wine products by origin, price range, vintage, and grape varietal) without writing repetitive SQL queries or brittle string concatenations.
