# HCMUNRE DACN 2026–2027 use case

This folder contains the two user-supplied official/source DOCX files for the Faculty of Information Technology specialized-project workflow. It is a **use case**, not the product boundary of WordAssistant.

- `assets/huong_dan_trinh_bay_dacn_2026_2027.docx`: report presentation guidance.
- `assets/mau_de_cuong_do_an_chuyen_nganh.docx`: proposal template.
- `source_audit_*.json`: measured DOCX geometry and SHA-256 provenance.

The `report` profile variant uses the written guidance as normative when embedded sample geometry conflicts. The `proposal` variant preserves the official proposal template's measured geometry because that file does not state a competing written page-geometry rule.
