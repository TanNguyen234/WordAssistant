# WordAssistant Universal Core Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver a compact, truthful, near-complete Word automation facade with deterministic core/OOXML operations, optional native Word workflows, agent discovery, and deep verification while preserving WordAssistant V2 behavior.

**Architecture:** Public CLI and `WordDocument` calls create typed operation requests. A registry, selector resolver, transaction coordinator, and deterministic router dispatch requests to python-docx, direct OOXML, Word-native, docx-mcp, or rendering backends and return a common fidelity-aware envelope. Capability discovery and documentation are generated from the same implementation registry.

**Tech Stack:** Python 3.10+, argparse, python-docx, lxml through python-docx, ZIP/OOXML package APIs, optional pywin32, optional LibreOffice, pytest.

**Spec:** `docs/superpowers/specs/2026-08-26-wordassistant-universal-core-design.md`

## Global Constraints

- Work only on `feat/wordassistant-v2-universal-core`.
- Do not rewrite history, force push, alter official HCMUNRE assets, or delete working behavior.
- Preserve existing V2.x CLI commands as compatibility aliases.
- Core operations must remain deterministic and API-key-free.
- Mutations support output-copy semantics, dry-run, JSON results, and fail-closed preflight where meaningful.
- A capability is advertised only when a callable implementation, automated test, available backend, and required health check agree.
- Capability evidence distinguishes structural validity, native Word round-trip, refreshed dynamic results, and visual verification. One passing dimension never implies another.
- Focused RED/GREEN tests run during implementation; the first full suite waits until source/config is stable.
- The live ten-page product is generated by Antigravity through Windows UI control, not directly by Codex.
- Logical commits and normal push occur only after final verification.
